How to use {{ platform_name }}

The essentials in two minutes.{% if help_video_url %} Prefer to watch? See the how-it-works video.{% endif %}

1. Send forms to a client

  1. Click New packet, type the client's name (earlier clients are suggested as you type).
  2. Tick the forms, or click a bundle to tick a set in one go. Add one-off files if needed.{% if has_approvals %} For a stone & seam layout choice or a template drawing, use those sections.{% endif %}
  3. Click Create signing link, then Open in my email or Text from my phone: your own email or phone opens with the message ready. Or Copy message and paste it anywhere.

2. Client in front of you?

Click Sign now on this device. The tablet shows only the signing pages; when they're done, enter your password to get back to your screens.

3. Keep track

  • The Packets page shows who has opened and signed, and New since your last visit lists what changed. Turn on desktop alerts there to get a pop-up while the app is open.
  • Follow-up lists who to remind today, with the reminder ready to send.
  • Record calls and notes in Follow-ups & notes on each packet.

4. Two owners

Choose Two owners must both sign. Each owner gets their own link; the second signs after the first. The packet page and Follow-up show when it's the second owner's turn.

5. Signed copies

When everyone has signed, the packet shows Signed. Use Download all for the signed PDFs, the audit trail and any files from the client in one ZIP. Clients download theirs from their link at any time.

6. Keeping documents private

Tick Require an access code on New packet for sensitive packets. Give the 4-digit code to the client by phone or in person, never in the same message as the link.

7. Is a signed PDF genuine?

Anyone can upload a signed PDF at {{ url_for('verify', _external=True) }} to check it's authentic and unchanged.

8. Questions and problems

  • Forgot your password? Ask a manager to reset it from the Team page.{% if support_name or support_phone or support_email %} Managers: contact {{ support_name or 'support' }}{% if support_phone %} at {{ support_phone }}{% endif %}{% if support_email %} or {{ support_email }}{% endif %}.{% endif %}
  • Client lost the link? Open the packet and send it again; use Extend link if it expired.
  • Page says the service is restarting? Wait a minute: the client's signature stays on the page and is sent automatically.
